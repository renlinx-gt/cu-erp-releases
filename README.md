# CU ERP Releases

Repositorio público dedicado exclusivamente a distribuir catálogos de versiones firmados con Ed25519 para **CU ERP Manager**.

- No contiene código fuente, claves privadas ni secretos.
- `lab/`: catálogo firmado para pruebas de laboratorio (`channel: lab`).
- `stable/`: reservado para futuros lanzamientos estables (`channel: stable`).
